The data sources you can connect, at a glance.

| Connector | Best for | Notes |
| --- | --- | --- |
| **Google Drive** | Syncing folders of documents | Point it at a specific folder, not the whole drive. |
| **SharePoint** | Connecting a site library | Common for clients with on-prem-leaning document management. |
| **File Upload** | Dragging in files directly | No external system; good for one-off document sets. |
| **Amazon S3** | Syncing a bucket prefix | Scope to a prefix rather than an entire bucket. |

## For every connector

- Files land in the **Doc Store** for the client (workstream) you're connecting to, and are isolated to it.
- A **sync** (one-time or scheduled) does the actual copying — connecting alone doesn't keep pulling. See [Sync settings and filters](/builder-guide/sync-settings-and-filters).
- Use include/exclude filters to pull only what's needed.
- Choose the most privacy-preserving connection option offered.

<Info>
  This matrix reflects the connectors described in Adopt's setup flow. The live **Connectors** page in the app is the source of truth — add rows here as new connectors ship.
</Info>
