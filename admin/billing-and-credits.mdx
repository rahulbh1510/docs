## Usage-based credits

Adopt meters usage and tracks it against **credits**. Admins can see consumption and manage credit allocation. Token consumption is visible for cost management, which helps you attribute cost to processes and clients.

## Bring your own key (BYOK)

For control over model costs, Adopt supports **bring-your-own-key** — you supply your own model-provider credentials and pay the provider directly, rather than consuming Adopt's included model usage. This pairs with **open-weight / self-hosted models**, a lower-cost or data-sovereignty option for suitable workloads.

## Managing spend

- Watch token consumption by process/agent to spot expensive workflows.
- Consider BYOK or open-weight models for high-volume, cost-sensitive processes.
- Set expectations with builders: tighter file scoping and cleaner instructions generally mean less token use per run.
