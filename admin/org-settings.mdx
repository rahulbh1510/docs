## What typically lives here

- **Organization profile** — name, domain, and identity settings.
- **Default policies** — org-wide defaults for access, retention, and notifications that new clients/engagements inherit.
- **Roles** — which roles exist and their capabilities (including any specialized platform roles your org uses).
- **Model configuration** — org-level model choices, including BYOK and any open-weight / self-hosted options.
- **Integrations** — org-level connections (for example, the Slack/Teams workspaces available for notifications).

## Good practice

- Set sensible org **defaults** so individual clients don't each need manual configuration — new engagements should inherit safe settings automatically.
- Keep **notification integrations** connected at the org level so end users can just pick a channel without doing an OAuth dance each time.
- Revisit org settings during your periodic access review.
