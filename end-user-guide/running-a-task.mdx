Most work in Adopt starts on its own — but you can also kick off a task yourself when you need something now. Here's both.

## Two ways work gets started

- **On a schedule** — most agents are set to run automatically (monthly, quarterly, or at period close). You don't start these; they arrive in your review queue when they finish.
- **On demand** — you can also run a task yourself when you need it now.

## Running a task on demand

<Steps>
  <Step title="Open the client">
    Open the client you're working on.
  </Step>
  <Step title="Choose the task">
    Pick the task you want to run (for example, "R&D Tax Credit" or "Reconciliations"). If several tasks exist for the client, pick the right one.
  </Step>
  <Step title="Check the files">
    Confirm the files it will use are in place. If files are missing, add them (see [Working with clients and files](/end-user-guide/clients-and-files)) — you can add them now, or the run will use whatever's there.
  </Step>
  <Step title="Start the run">
    Start the run. You don't have to wait on the screen.
  </Step>
</Steps>

## What happens during a run

The agent reads the client's files, does the preparation described by the task, and produces output. Depending on the work, this can take anywhere from under a minute to several minutes.

When it finishes, the result goes to your review queue and you're notified (if [notifications](/end-user-guide/notifications) are on).

## After the run

Everything an agent prepares waits for your review — it is never final on its own. Head to [Reviewing and approving work](/end-user-guide/reviewing-and-approving) to check and approve it.

<Note>
  Occasionally a run stops with an error — a missing file, a source that didn't sync. You'll see it flagged; see [When a run fails](/troubleshooting/when-a-run-fails).
</Note>
